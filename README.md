# Projetos Práticos de Infraestrutura

Portfólio de estudos e projetos em Infraestrutura, DBA e Automação.

## Objetivo

Este repositório reúne laboratórios e scripts desenvolvidos durante minha transição e 
aprofundamento em infraestrutura. O foco é documentar a aplicação prática de conceitos de SysAdmin, 
Banco de Dados e DevOps.

## Tecnologias

- **Sistemas:** Linux (Debian/Ubuntu)
- **Banco de Dados:** PostgreSQL, SQL
- **Automação:** Bash
- **Containers:** Podman, Docker
- **CI/CD:** GitHub Actions
